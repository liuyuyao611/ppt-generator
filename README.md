# SlideCraft · 文档生成可编辑 PPT

使用 **Streamlit + python-pptx**。支持 DOCX、带文字层的 PDF、Markdown、TXT、粘贴文字；不需要数据库或安全隧道。
默认规则模式无需 API。它按原文分段摘选，完整段落保留在讲稿备注；可选 AI 模式负责整理内容。

## 个人学术汇报

在「页面风格 → 配色与风格」选「个人学术汇报」。导入文档，或点「从空白页开始」。在「编辑大纲」填任意标题与正文、分配多张图片，并为每张图填写图注或选对应要点。可以改页序、选择是否生成封面，或在单页选择版式和图文空间侧重。正文中的 `**词组**` 用于加粗，`==词组==` 用于红色加粗。

规则模式优先摘取含目标、方法、比较、结果和限制的原文要点，每页备注列出来源。AI 整理可从兼容服务获取提炼后的大纲。在纯文字页的「版式与讲稿」中勾选「把本页变成图」，可将合适的内容改成可编辑的步骤图、任务块或对照图。原文、标题与已有要点继续保存在大纲里。

显式对照的两句如果都采用「组别：指标 数值 单位」且指标、单位一致，还可以生成可编辑的数值对比条。需要概念插图时，在该页勾选「按本页文字生成概念插图」，编辑插图描述并用有图片模型权限的 OpenAI API Key 确认生成。插图是图文排版中的独立图片，带有 AI 概念示意标注。用于 AI 整理文字的 DeepSeek Key 与图片功能分开使用。

维护者可在环境变量或 Streamlit Secrets 中配置 `PERSONAL_TEMPLATE_PATH`，指向服务器上可读取的 PPTX。托管环境也可通过私有配置提供该文件的 Base64 文本 `PERSONAL_TEMPLATE_BASE64`。路径优先。设置后网站默认使用该模板；自行试用时也可在当前会话上传模板。模板第 1、2 张示例页分别指定封面和正文版式，适用 16:9 或 4:3，建议使用只含共享母版和版式元素的精简副本。

例如，本地可以用 `PERSONAL_TEMPLATE_PATH="/path/to/template.pptx" streamlit run app.py`。模板母版、版式和其上的原生对象会进入导出的 PPTX，示例页及其内容不会进入成品。浏览器近似显示部分母版效果；最终请在 PowerPoint 核对字体、母版背景和图内标注。参考材料通过私有配置或会话导入。项目仓库只需保存应用代码。

## PDF 文字读取

逐页检查文字层的缺字、私用字符和异常混杂编码。发现可疑页面时，自动使用
Poppler 重新读取；仍无法可靠解码时停止生成并提示 OCR，不将乱码写入大纲。
“原文与来源”可查看逐页读取结果。规则模式合并正文的视觉换行，避免将独立公式、
页码和重复页眉当成要点；原始提取文字（含公式片段）仍保留在来源与 PPT 备注中。
扫描页仍需先 OCR；编码检查不能代替人工核对数学公式、表格和多栏阅读顺序。

Streamlit Cloud 会从 packages.txt 安装 poppler-utils 和 poppler-data（含中文字体映射）。
本地运行可安装 Poppler 并把 pdftotext 加入 PATH；没有它时仍可读取正常的文字 PDF，
但不能修复有问题的字体编码。备用解析通过内存管道传入、传出，不将上传文件写到磁盘，
不新增模型调用，也不消耗 API 额度。

## V3：Frontend Slides 动态演示

生成大纲后，打开“动态演示 · Frontend Slides”标签页。
先比较当前标题的三种真实封面，再选择风格与阅读/演讲密度：

- Electric Studio：来自 Frontend Slides 安全预设，蓝白分区、Manrope 字体。
- Signal：来自其 Bold Template Pack，深蓝、纸白、金色和 Source Serif 4 / DM Sans；选择后读取对应的完整设计资料。
- Research Atlas：针对科研汇报实现的自由设计，浅纸色、深绿、网格与边框。

完整包含上游 viewport-base.css，使用 1920×1080 固定画布等比缩放。
不为手机重排正文；支持全屏、方向键、空格、Page Up/Down、滑动、讲稿和减少动态效果。
网页内嵌模式只在全屏时启用滚轮翻页，以免阻碍网站本身的滚动。
HTML 内嵌原图与开放字体，不依赖 CDN、外部字体服务、npm 或模型调用，下载后可以离线打开。
中文字体按当前文稿字符子集内嵌；大幅新增文字可导回网站重新排版。

按 E 或点击左上角编辑文字。修改在本机浏览器暂存，可保存为新的独立 HTML。
点击“下载修改 JSON”，然后在本网站同一标签页上传并应用，即可将修改导回大纲并重新生成 PPTX。
换行会按新的正文要点处理；编号、文献出处等不作为自由编辑字段。
来源标签不会被修改文件覆盖，修改后仍需对照原文核对事实。
本机浏览器暂存仅用于演示编辑，可用演示中的“清除本地修改”恢复。

对应 PPTX 使用相同的文字、图片、排版场景与颜色，保留原生文字框和图形。
PPTX 是静态版本，不包含网页动画，不嵌入字体；打开设备的字体替换可能影响显示。
完整文稿包含动态 HTML、静态 PPTX、大纲、来源、检查记录、主题配置与字体/代码许可。

这不是把技能说明交给云端 Codex 运行，而是将其样式发现、固定舞台、动效、导航、
离线 HTML 和编辑流程实现为独立网站功能。第一版提供上述三种适配风格，
没有声称完整实现上游的全部 34 种 Bold 风格、任意 PPT 保真转换、Vercel 自动部署或自动 PDF 导出。
科学内容整理仍由原来的规则/可选 AI 模式负责，不调用新模型或新增数据库。

上游：[zarazhangrui/frontend-slides](https://github.com/zarazhangrui/frontend-slides)，MIT。
使用的资料、原版 CSS、许可证及开放字体位于 assets/frontend-slides。

## V2：多版式与文献汇报流程

自动推荐九种内容版式：重点聚焦、并列卡片、左右对照、步骤流程、图文并排、文献概览、总结收束、双栏和简洁列表。
根据标题、明确的内容关系、文字长度与选图推荐，允许逐页覆盖；不会为了换版式给独立研究强加流程关系。
“为全部页面重新推荐版式”保留已编辑文字，不再次调用模型。缩略图可以检查整套页面的变化。
预览使用浏览器本地翻页和轻量过渡，无需逐页请求服务器或重新运行 Streamlit；支持上一页/下一页、跳页、方向键和手机左右滑动，并尊重系统的减少动态效果设置。
新增“组会蓝橙”配色。参考 PPT 仍只提供配色、字体与比例，不等同于任意母版复刻。

规则分段优先保留章节边界，不再为了满足目标页数把相邻章节拼在同一页；实际页数可能增加。
每页可编辑目的、内容关系、讲稿及图片出处；源 PDF 页码和 DOI 文本候选保留在来源记录。
可提取 PDF 内嵌图片供手动选图；这些图片可能是拼图局部、Logo 或缺少坐标的面板，需人工核对，不自动推断图号。

本版本将用户指定的 paper-to-editable-slides 流程转化为独立网站能力：

- 大纲中记录逐页目的、正文、来源、内容关系和图片出处。
- 通过同一排版场景生成独立 HTML 与原生可编辑 PPTX；正文不转曲、不整页栅格化。
- skill_audit.py 从该本地技能的 audit_editability.py 移植，增加字节输入，实际用于导出检查。
- 每个正文段落分配稳定 ID，对应一个原生文字框；长段落续页时每个段落片段仍在一个框内。
- 完整文稿包包含 PPTX、HTML、outline.json、style.json、evidence.json、checks.json。

接入边界：网站不运行 Codex 智能体，不会自动阅读全文并完成科学事实审稿，也没有复制任意 HTML/CSS 的能力。
网站通过共同的语义场景并行生成 HTML 和 PPTX，不是假称执行任意 HTML → SVG → PPTX 编译。
原生编辑性检查使用内部语义清单，不把该清单作为视觉 SVG 交付；它不等于通过浏览器 SVG 的严格 no-tspan 检查。
默认不附加 SVG，用户明确勾选后才在文稿包内附加使用 tspan 的浏览器 SVG，保留一个 text 容纳一个段落。
此 SVG 不承诺 PowerPoint“转换为形状”后不拆字；推荐编辑原生 PPTX。
检查器仅检查结构与文本一致性，不替代逐页视觉检查或事实核对；未声称已在原生 PowerPoint 中实测。

## 本地启动（Python 3.11 / 3.12）

在本项目目录打开终端：

~~~powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
~~~

macOS / Linux 将 Python 路径替换为 .venv/bin/python。浏览器打开终端显示的 localhost 地址。
Windows 可双击 start.bat（首次启动需要下载依赖）。
安装完成后，运行 python verify.py 可检查读取、排版、导出与 Streamlit 界面流程。

## 部署到 Streamlit Community Cloud

1. 创建 GitHub 仓库，将本目录的源码上传。不要上传 .venv、用户文档或 .streamlit/secrets.toml。
2. 登录 https://share.streamlit.io/，选择 Create app，填写仓库、分支和入口 app.py。
3. Advanced settings 选 Python 3.12；需要 AI / 访问码时设置 Secrets，配置格式见 .streamlit/secrets.toml.example。
4. 点击 Deploy。部署成功后，Streamlit 会提供实际的 .streamlit.app 网址，分享该网址即可。

如果把项目放在仓库子目录，入口填写 子目录/app.py，requirements.txt 与 app.py 放在一起。
官方部署说明：https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy

## 使用

1. 上传或粘贴正文，也可载入示例。
2. 可选：上传参考 PPT、导入 style.json、上传 PNG/JPG。参考 PPT 只提取配色、字体和比例，不复刻复杂母版。
3. 选择规则分段或 AI，设置目标页数，生成大纲。
4. 逐页修改标题、每行一条的要点、讲稿、版式与配图。原文标签 S1、S2 等可在“原文与来源”查询。
5. 在预览中检查页面，点击“生成 PPTX 下载文件”，再下载 PowerPoint。修改内容后需重新生成下载文件。
6. 可下载大纲 JSON 与样式 JSON 另行保存。页面刷新、重启或云端休眠后，会话可能丢失。

文字、色块为可编辑原生对象，图片保留为图片。长要点自动流到续页，所以实际页数可能多于目标。
预览与导出使用同一套坐标和显式换行。预览并非 PowerPoint 渲染；设备字体替换可能影响实际观感。
建议中文字体使用 Microsoft YaHei、等线或 Noto Sans CJK SC，并在打开 PPT 的电脑上安装对应字体。

## 可选 AI 配置

默认不调用模型。AI 模式使用兼容 Chat Completions 的 HTTPS 服务（/chat/completions），
页面可选择 OpenAI、DeepSeek 或「站点默认」，并使用对应服务的 API Key 和模型名称。
支持直接填写个人 Key；服务地址只由部署者配置，网页访客不能修改。
需要模型支持 max_tokens 参数和 JSON 文本输出。不同服务与模型的兼容性须实际验证。

在 Streamlit Cloud 的 Secrets 中按需设置：

~~~toml
OPENAI_API_KEY = "你的服务密钥"
OPENAI_MODEL = "你的服务支持的模型名称"
OPENAI_BASE_URL = "https://api.openai.com/v1"
APP_ACCESS_CODE = "可选的班级访问码"
~~~

没有配置 Key 时，访客可在页面填写自己的 Key。Key 不写入项目文件。
使用 AI 前需要勾选同意发送文档文字；只发送文字，不发送图片。AI 可能遗漏或误读，务必核对。
如果公开分享部署者的付费 Key，建议设置访问码；访问码仅用于小范围共享，不代替完整的用户与额度系统。
本项目没有账户、计费、数据库或跨实例限流。

## 资源与数据边界

- 单个文件最多 20 MB，正文最多 10 万字符，PDF 最多 120 页。
- Office ZIP 包解压总量最多 100 MB；图片最多 24 张，处理后图片合计最多 30 MB。
- AI 单次最多约 4.5 万字符；超过限制会拒绝，不会静默截断。每次点击只发起一次请求，无自动付费重试。
- 扫描 PDF 不做 OCR；混合扫描 PDF 会提示可疑页。PDF 内嵌图可提取，完整图表也可作为补充图片上传。
- DOCX 读取正文与表格、载入内嵌图片。图片与要点的对应关系由用户手动选择。
- 不支持旧版 .doc、公式转换、复杂表格原样复刻、动画或自动科学绘图。
- 文件只存当前 Streamlit 会话内存；不使用跨用户文档缓存，不写文档到磁盘。AI 服务的数据保留政策由服务商决定。
- 免费云端存在资源、重启与休眠限制；本项目未实现后台任务与持久保存。
- 科研图表、数字、文献与结论均需用户审核；规则模式只摘选原文，AI 模式不能保证内容事实正确。

## 代码结构与技能关系

- app.py：上传、设置、大纲编辑、预览与下载。
- core.py：文件读取、来源标签、规则大纲、可选 AI、大纲与样式校验。
- renderer.py：共同排版场景、自动续页、SVG 版式预览、原生 PPTX 导出。
- layouts.py / layout_engine.py：内容关系推荐、九种版式和保留文字的自动续页。
- exports.py：HTML、文稿包、原文证据记录与检查器接入。
- skill_audit.py：来自本地 paper-to-editable-slides 的编辑性检查器（增加内存输入）。
- style.json：默认配色、字体和比例，可在网页中导入/导出。
- examples/：不含实测数据的演示材料。
- verify.py：离线功能与界面测试。

设计参考了本机 ppt-master 技能的“大纲先行、内容与排版分离、原生文字可编辑、检查后导出”原则。
网站主体为独立 Python 实现；V2 包含上述 paper-to-editable-slides 检查脚本的适配版，不在云端执行本机 Codex 智能体。
技能说明不是可直接运行的模型引擎；不需要把整个 .codex/skills 上传 GitHub。
如需固定背景、Logo、复杂母版或新增特定技能的处理流程，可在此基础上扩展。

无需预先放置 template.pptx。未提供实际模板时使用内置布局；参考 PPT 和样式 JSON 均可在网页上传。
