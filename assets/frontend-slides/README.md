# Frontend Slides resources

Source: https://github.com/zarazhangrui/frontend-slides

The fixed-stage viewport CSS is included in full in generated dynamic HTML.
Style selection adapts Electric Studio from STYLE_PRESETS.md, Signal from the
Bold Template Pack, and a locally authored Research Atlas wildcard.
Only Signal's selected design recipe is read for full-deck generation.
The installed local skill supplied these reference files; this folder is a
runtime resource subset, not an executable copy of the complete coding agent.

MIT copyright and license are preserved in LICENSE and in generated HTML/bundles.
fonts/ contains Google Fonts assets and their original Open Font Licenses.
fonts/manifest.json records upstream blob identities, download URLs and hashes.
The CJK font is subset locally to the current document; Latin webfonts and all
required image/font data are embedded into the standalone presentation.

No CDN/font request, remote script, shell deployment helper or model call is
executed by the presentation player.
